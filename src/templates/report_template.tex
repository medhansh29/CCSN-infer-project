\section{Methodology \& Anomaly Definitions}
\textit{This section outlines the physical scaling relations, mathematical thresholds, and Bayesian diagnostic criteria used by the automated pipeline to flag anomalous objects.}

\subsection*{Energetic \& Scaling Deviations}
Flags in this category denote a fundamental violation of the expected mass, energy, or luminosity budget for a standard Type IIP explosion.
\begin{itemize}
    \item \textbf{Luminosity Excess:} The expected plateau magnitude ($M_{exp}$) is calculated via scaling relations based on the inferred $ZAMS$ and explosion energy ($E_k$). An object is flagged if the observed absolute magnitude ($M_{obs}$) deviates significantly: 
    $|M_{obs} - M_{exp}| > 0.75 \text{ mag}$
    \item \textbf{Mass Budget Violation:} Evaluates the specific kinetic energy. Flagged if unphysically high for a standard IIP:
    $(E_k / M_{ej}) > 1.0 \text{ } (10^{51}\text{erg} / M_\odot)$
    \item \textbf{Nickel Overabundance:} Evaluates the radioactive tail fraction. Flagged if the ratio suggests anomalous radioactive heating:
    $(M_{Ni} / M_{ej}) > 0.01$
\end{itemize}

\subsection*{Morphological \& Light Curve Outliers}
Flags in this category track global shape deviations from standard hydrogen recombination models.
\begin{itemize}
    \item \textbf{Extreme Plateau Extension/Truncation:} The observed plateau duration ($t_{obs}$) is compared to the theoretical duration derived from the inferred physical parameters ($t_{exp}$). Flagged if:
    $|t_{obs} - t_{exp}| > 20 \text{ days}$
\end{itemize}

\subsection*{Progenitor Environment \& Shock Breakout}
Flags in this category denote local environmental interactions, specifically eruptive pre-supernova mass loss and early shock interaction with Circumstellar Material (CSM).
\begin{itemize}
    \item \textbf{Precursor Detection:} A rolling baseline mean ($\mu$) and standard deviation ($\sigma$) are calculated for photometry prior to $t_{exp} - 10$ days. A flag is triggered if the immediate pre-explosion window ($t_{exp} - 10$ to $t_{exp}$) contains $\ge 2$ consecutive detections where $Flux > \mu + 3\sigma$.
    \item \textbf{Early Rise Excess:} A standard fireball expansion curve ($f \propto t^2$) is fit to the first 3 days of photometry. Flagged if early observations exhibit a $>0.1$ magnitude excess above the $t^2$ fit, indicating shock breakout in dense CSM.
    \item \textbf{Arrested Cooling:} Measures the early color gradient. Flagged if the ejecta remains artificially blue across the first 15 days ($d(g-r)/dt < 0.04$ mag/day).
\end{itemize}

\subsection*{Plateau Topography}
Flags in this category address non-standard behavior during the hydrogen recombination phase.
\begin{itemize}
    \item \textbf{Rebrightening Bump:} Identifies periods where flux actively increases during the plateau (days 20-70). Flagged if $dm/dt < 0$ for a contiguous span of $> 5$ days.
    \item \textbf{Linear Residual Excess:} A simple linear regression is fit to the plateau. Flagged if a contiguous cluster of residuals peaks $\ge 0.1$ magnitudes above the fit.
\end{itemize}
